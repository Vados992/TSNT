# Contributing

1. Open an issue describing the model, data, or software change.
2. Add provenance and units for new fields.
3. Add tests, including edge cases and a leakage test for time-dependent data.
4. Run ruff, mypy and pytest.
5. Document assumptions, failure modes and any calibration interval.

Never commit secrets, licensed raw data, personal data, or classified material.
Changes to equations require a methodological note and an independent review.

# Security policy

Report vulnerabilities privately to the repository owner. Do not open a public
issue containing credentials, protected data, exploitable infrastructure
details, or personal information.

TSNT accepts only authorised data. Secrets belong in a secret manager or local
environment, never in Git. Production deployments must use authentication,
least privilege, encryption, audit logging, network segmentation and an
independent human approval process for consequential decisions.

The engine is analytical decision support, not an autonomous targeting,
sanctions, policing, or military command system.

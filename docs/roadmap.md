# Roadmap

## Implemented in the reference engine

- strict domain and API contracts;
- bitemporal multilayer snapshots;
- exact SNII scoring;
- max-flow and min-cost LP;
- Leontief and constrained IO;
- bounded cascade simulation;
- seeded Monte Carlo summaries;
- recovery metrics;
- forecast, interval and reliability metrics;
- lineage, units and duplicate-flow gates;
- SQL schema, API, CLI, containers and tests.

## Next empirical milestones

1. Freeze a lawful source registry and licensing matrix.
2. Build one maritime/trade pilot at aggregate resolution.
3. Construct versioned capacity and alternative-route estimates.
4. Map one reviewed IO edition and reconciliation table.
5. Pre-register Suez/Ever Given and Panama drought backtests.
6. Run independent analyst scoring and publish ICC/Kendall results.
7. Hold out Red Sea or another event family from all tuning.
8. Perform prospective shadow operation without decision authority.
9. Complete security, privacy, legal and model-risk review.
10. Promote only components that meet pre-declared acceptance gates.

## Explicitly not complete

A public repository cannot supply globally complete licensed AIS, commercial
capacity, cable, financial, military or legal feeds. Connector seams are
therefore fail-closed. Empirical readiness is achieved source by source through
authorisation, reconciliation and held-out validation—not by replacing absent
measurements with synthetic values.
